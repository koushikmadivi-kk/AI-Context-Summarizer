✅ 1. Explanation of Each Part
🅰️ Frame

What it does:
The skeleton of the drone. Holds everything together.

Types:

450mm (beginner friendly, stable)

Carbon fiber (light & strong)

Tip: Bigger frame = more stable, smaller = more agile.

🅱️ Motors (4x – Brushless)

What they do:
Spin propellers to create lift.

Important specs:

KV rating (RPM per volt)

800–1000KV → large prop, stable drone

2200KV → small prop, fast drone

Each motor spins either clockwise (CW) or counter-clockwise (CCW).

🅲️ ESC (Electronic Speed Controller) – 4x

What it does:
Controls motor speed based on signals from flight controller.

Think of it as:
Motor’s power manager.

Each motor needs 1 ESC.

🅳️ Propellers (4x)

What they do:
Push air down to lift drone up.

Two types:

2 clockwise (CW)

2 counter-clockwise (CCW)

Never mix direction incorrectly.

🅴️ Flight Controller (Brain of drone)

What it does:
The brain of the drone.

It:

Stabilizes drone (gyro + accelerometer)

Processes remote signals

Controls ESCs

Popular firmware:

Betaflight

INAV

Ardupilot

🅵️ Battery (LiPo)

What it does:
Powers everything.

Example:

3S (11.1V)

4S (14.8V)

Higher voltage = more power.

⚠️ LiPo batteries are dangerous if mishandled.

🅶️ Power Distribution Board (PDB)

What it does:
Distributes battery power to:

ESCs

Flight controller

Other modules

Some flight controllers have built-in PDB.

🅷️ Receiver (RX)

What it does:
Receives signals from your remote controller.

Examples:

FlySky

FrSky

ELRS

🅸️ Camera + Video Transmitter (Optional)

Used for:

FPV flying

Live video transmission

🗺️ 2. Learning Roadmap (Beginner to Advanced)
Phase 1 – Basics (1–2 weeks)

Learn:

How brushless motors work

How ESC works

What is PWM signal

What is LiPo battery

Basic soldering

Practice:

Solder wires

Use multimeter

Phase 2 – Electronics Understanding

Learn:

Power flow in drone

Battery → PDB → ESC → Motor

Signal flow: Receiver → Flight Controller → ESC

Phase 3 – Assembly Practice

Start with:

450mm frame

1000KV motors

30A ESC

3S battery

Avoid racing drone first.

Phase 4 – Flight Controller Setup

Learn:

Flash firmware

Calibrate ESC

Set flight modes

PID tuning basics

Phase 5 – Advanced

GPS

Return to home

FPV system

Autonomous flight

🔧 3. Step-by-Step Assembly Guide
Step 1: Assemble Frame

Fix arms to base plate

Tighten screws properly

Ensure frame is square

Step 2: Mount Motors

Attach 1 motor to each arm

Use thread lock

Don’t overtighten

Step 3: Install ESCs

Two options:

Mount on each arm

Or inside frame

Secure using zip ties or heat shrink.

Step 4: Mount Power Distribution Board (PDB)

Fix at center of frame

Insulate bottom (very important)

Step 5: Solder Power Wires

Connect:

Battery connector → PDB

ESC power wires → PDB

⚠️ Double check polarity (+ and −)

Step 6: Connect ESC Signal Wires

Each ESC has:

Signal wire

Ground wire

Connect to:
Flight Controller motor outputs (M1, M2, M3, M4)

Step 7: Mount Flight Controller

Use vibration dampers

Arrow facing forward

Secure firmly

Step 8: Connect Receiver

Receiver → Flight controller

SBUS / IBUS / CRSF port

Bind with remote.

Step 9: Install Propellers (LAST STEP!)

Very important:

Motor directions:

Front Left  – CCW
Front Right – CW
Rear Left   – CW
Rear Right  – CCW

Match propeller type correctly.

Never install props during testing.

⚡ 4. Basic Wiring Flow
🔋 Power Flow:

Battery → PDB → ESC → Motor

📡 Signal Flow:

Remote → Receiver → Flight Controller → ESC → Motor

🚀 5. First Flight Checklist

Before powering:

✅ No short circuit
✅ Battery polarity correct
✅ Motors spin correct direction
✅ Receiver bound
✅ Flight controller calibrated
✅ Props installed correctly
✅ Tight screws

🛑 Important Safety Rules

NEVER test with propellers on

Always remove props while configuring

Don’t over-discharge LiPo

Keep fire-safe bag for battery

Fly in open area first
